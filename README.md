## Satranç 3B

`Satranc3D.html` dosyasını tarayıcıda açarak 3 boyutlu satranç oynayabilirsiniz (bilgisayara karşı veya iki kişi). Taşlar mitolojik bir tapınak salonunda duran taş heykellerdir; taş alındığında saldıran heykel rakibini parçalar. Tüm kurallar desteklenir: rok, geçerken alma, terfi, şah mat, pat ve beraberlik kuralları.

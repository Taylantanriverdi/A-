## UO_Projem – Ultima Online yerel sunucu altyapısı

`UO_Projem/` klasörünün içeriğini Windows'ta `C:\UO_Projem\` içine kopyala ve sırayla çalıştır:

1. `1_Kurulum_ve_Derleme.bat` – git/.NET SDK kontrolü, ServUO + ClassicUO indirme, derleme, ayarlar
2. `2_Oyunu_Baslat.bat` – Saves yedeği, sunucuyu başlatma, port 2593 hazır olunca ClassicUO
3. `3_Online_Moduna_Gecis.bat` – VDS/VPS'e taşırken dış IP'yi Server.cfg ve settings.json'a yazma

Ayrıntılar: `UO_Projem/OKU_BENI.txt`. Ortak ayarlar: `UO_Projem/Araclar/ayarlar.cmd`.
